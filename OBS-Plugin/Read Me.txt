Icecast Control: OBS plugin

Sends OBS's stream audio to your Icecast stream (through the Icecast Control app),
so radio listeners hear the same audio as your video stream. It starts and stops
together with OBS streaming.

Install
  1. Make sure Icecast Control is installed and set up.
  2. Double-click "Install OBS Plugin.command".
     The first time, macOS may block it: open System Settings → Privacy & Security
     and click "Open Anyway", then double-click it again.
     (Or right-click the file → Open.)
  3. In Icecast Control, set the Broadcast input to "OBS".

That's it. Whenever OBS is open, streaming or not, the OBS input in Icecast Control
plays OBS's audio. Press Go Live in Icecast Control to put it on air.

Options (OBS → Tools → Scripts → icecast-control-obs.lua)
  • Audio track: use the track your stream uses (usually 1).

Remove: double-click "Uninstall OBS Plugin.command".
Manual install: OBS → Tools → Scripts → + → choose icecast-control-obs.lua.
